# Pearl for iPhone

A native SwiftUI app for Pearl. It talks to the same Pearl server as the web
app (https://ledger-six-lac.vercel.app by default), so your accounts, answers
and rules are the same in both. Nothing about your bank connections changes.

## What's in it (first version)

- **Sign in** with an email code, or a username and password. The first time
  this iPhone signs in, Pearl asks you to approve it from a device you've
  signed in on before (Pearl on the web shows the request), or with a
  recovery code. It stays signed in after that.
- **Home**: what needs you, "Set Pearl up again" after a Start over, and how
  the month is going against your usual.
- **Cash flow**: transactions a month at a time, search across everything,
  and a transaction's details with "Change category" (and "Do the same for
  every …").
- **Needs a look**, one at a time: confirming a category, "Is this income?"
  (your regular pay, other kinds, your own money, a cash deposit, savings,
  a loan, not yours), and the kind of income, with Undo. Paybacks, refunds,
  reimbursements and joint-account questions are answered on the web for now;
  the app lets you skip them.
- **Profile**: sign out, and a link to Pearl on the web for everything else.

## Run it

1. Open `ios/Pearl.xcodeproj` in Xcode (15 or later).
2. Choose an iPhone simulator at the top and press Run (⌘R).
3. To run it on your own iPhone: select the **Pearl** target › **Signing &
   Capabilities**, choose your Apple ID under **Team** (a free one works),
   plug in your iPhone, pick it at the top, and Run. The first time, approve
   the developer on the iPhone in Settings › General › VPN & Device
   Management.

## Developing against a local server

On the sign-in screen, open **Server** and enter `http://localhost:5050`
(the simulator can reach your Mac's localhost). Run Pearl locally with
`python app.py`. **Use Pearl's server** puts it back.

## Adding a file

Xcode's project file is generated. After adding or removing a `.swift` file
under `ios/Pearl`, run:

```
python3 ios/tools/make_project.py
```

## Layout

```
ios/
  Pearl.xcodeproj/          generated by tools/make_project.py
  Pearl/
    App/                    the app, signed-in state, formatting
    API/                    the server connection and what it sends
    Theme/                  Pearl's colours and type
    Views/                  Sign in, Home, Transactions, Needs a look, Profile
    Assets.xcassets/        icon and accent colour
    Info.plist              allows http://localhost while developing
  tools/make_project.py
```
